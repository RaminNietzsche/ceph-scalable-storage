# SEO and web best practices of the web edition

Everything is generated by `tools/build_site.py` (with `tools/booklib/seo.py`) and is static and offline: no trackers, no analytics, no CDNs, no external fonts or scripts.

## Per page

- A unique `<title>` and `<meta name="description">`. The description is the page's first real paragraph (cut at a word, about 155 characters); app pages use their own intro strings. Long chapter titles drop the book name from `<title>`.
- `<html lang dir>` (`fa`/`rtl`, `en`/`ltr`).
- `hreflang` alternates for `fa`, `en` and `x-default` (the language chooser).
- `<link rel="canonical">` only when `SITE_URL` is set (`make site SITE_URL=https://example.org/ceph`). Without it, canonical links are left out and other URLs stay relative, so the site still works from `file://`.
- Open Graph and Twitter card tags. The card image `assets/og.<lang>.png` (1200×630) is drawn at build time from the cover, with the title shaped by raqm for Persian.
- JSON-LD:
  - The edition home has `WebSite` with a `SearchAction` (`index.html?q=…`, which opens the offline search) and `Book`. `Book` carries the author Ramin Najarbashi, the CC BY-NC-SA 4.0 licence, `inLanguage`, `hasPart` (every chapter) and a link to the other-language edition.
  - Every other page has a `BreadcrumbList`; chapters also have a `Chapter`.
- One `<h1>`.
- Images have alt text: figures use their caption and covers a descriptive sentence. They also have `width`/`height`, and everything below the fold uses `loading="lazy"`.
- Link text is meaningful. Number-only links (chapter chips, index references) carry an `aria-label`.
- A preload of the main font (Vazirmatn or Inter). Chrome rejects crossorigin preloads from `file://` with console errors, so a one-line inline script adds the preload link only over http(s).
- CSS and JS references carry `?v=<content hash>`, so they can be cached for a year.
- Favicons (`favicon.ico`, SVG, apple-touch-icon), `theme-color` and a web manifest (`manifest.webmanifest` per edition and at the root).

## Site-wide

- `sitemap.xml` lists both editions, each URL with its `hreflang` alternates. Its URLs are absolute when `SITE_URL` is set.
- `robots.txt` gets a `Sitemap:` line when `SITE_URL` is set.
- `404.html` is bilingual and `noindex`, with links to both homes and contents pages. It gets `<base href>` when `SITE_URL` is set.
- `_headers` (Netlify/Cloudflare Pages) and `.htaccess` (Apache) hold the cache policy and the 404 rule.

## Checks

`make check-site` runs `tools/check_site.py` (links, anchors, offline-only resources) and then `tools/check_seo.py`. The SEO check asserts all of the above for every page and fails the build on any problem; `--report` prints the per-check counts.
